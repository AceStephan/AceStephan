### How I approach a build

**Start with the marketing outcome.** Understand what helps the team publish, attract visitors, or serve creators better.

**Trace the source.** Fix the underlying data or integration before polishing the dashboard.

**Verify the result.** Check the stored data, the output, and the experience someone actually sees.

**Make it maintainable.** Leave clear instructions, useful failure messages, and a workflow another person can follow.
